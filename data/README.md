# Data

The study uses the public **IBM Telco Customer Churn** sample dataset. It is not redistributed in this repository.

1. Download the Excel version of the IBM Telco customer churn sample from IBM's public sample-data page.
2. Save it here as `Telco_customer_churn.xlsx`
   (the notebook reads `../data/Telco_customer_churn.xlsx`; change `DATA_PATH` in the notebook if you use another name).

The dataset is a proxy for subscription behaviour. It is not B2B SaaS data.
